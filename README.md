## Every layer of the yard

| Discipline | What I did |
|---|---|
| **Electrical engineering** | Load calculations, MSB, DG sets, TRU and NAVCOM on live vessels — class-witnessed commissioning |
| **Hull production** | Structural fabrication, block assembly, production scheduling |
| **CNC nesting** | Plasma and oxy-fuel nesting, steel yield, remnant control, production BI |
| **IT infrastructure** | WAN/LAN, Windows Server, Active Directory, NAS, firewalls, surveillance |
| **Digital transformation** | Zoho platform, workflow automation, compliance and audit systems |
| **Software** | Maritime web apps, APIs and internal tools |

## Live tools

| App | What it does | Stack |
|---|---|---|
| [**MarineElect**](https://marineelect.sujikumar.com) | Multi-vessel ship electrical management — switchboard analysis, fault logs, class survey alerts | Next.js · TypeScript |
| [**ShipDash**](https://shipdash.sujikumar.com) | Maritime engineering toolkit — cable sizing, plasma estimator, SOLAS timers; offline PWA and Android app | Next.js · PWA |
| [**REX Maritime AI**](https://rex.sujikumar.com) | Maritime AI assistant — SOLAS, MARPOL and class-rule Q&A, PDF manual Q&A | Cloudflare Workers AI |
| [**OffsetCalc**](https://offsetcalc.sujikumar.com) | Hull offset tables, Simpson's Rule hydrostatics, 3D hull viewer | Next.js · Three.js |
| [**ShipTrace**](https://shiptrace.sujikumar.com) | Self-hosted NCR and defect tracking with Pareto analytics | Next.js · Docker |
| [**ShipPipe**](https://shippipe.streamlit.app) | Marine piping designer — 12 ship systems, ASME B36.10M sizing, BOM | Python · Streamlit |
| [**TidePilot**](https://tidepilot.sujikumar.com) | Tides, port schedules and coastal planning for marine operations | Next.js · TypeScript |
| [**EnginePulse**](https://enginepulse.sujikumar.com) | Marine engine test suite | JavaScript |
| [**GearLab**](https://gearlab.sujikumar.com) | Gearbox engineering calculator (AGMA / ISO 6336) | JavaScript |
| [**AISPulse**](https://aispulse.onrender.com) | Live AIS vessel tracker | Go · Leaflet |
| [**MarineElect Sim**](https://sim.sujikumar.com) | Manoeuvring simulation — zig-zag and turning-circle tests | Next.js · TypeScript |
